# The Truth About That Day

A static, dark-academia-inspired English learning game focused on personal letters, listening comprehension, evidence evaluation, and inference.

## Files
- `index.html` — main game interface and chapter structure
- `style.css` — responsive visual design
- `script.js` — navigation and local progress saving
- `assets/audio/` — planned location for recorded audio

## Preview locally
Open `index.html` in a modern browser. No build step is required.

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `main` branch and `/ (root)`, then save.
4. Wait for GitHub Pages to publish the site.

## Current status
This is the first playable navigation prototype. The complete listening activity, evidence interactions, hearing, verdict, and scoring are being built in stages. Progress is saved locally in the current browser only.
